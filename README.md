# Rotaract Club of University of Moratuwa - IT Team Recruitment Task

This repository contains the source code for the Mini Web Development Task: a time slot booking web application. It allows users to book available time slots while preventing duplicate or overlapping bookings.

## 🚀 Technology Stack

**Frontend:**
- React (with Vite & TypeScript)
- Tailwind CSS
- shadcn/ui

**Backend:**
- FastAPI (Python)
- SQLModel (ORM)
- PostgreSQL (Supabase)

**Deployment:**
- Frontend & Backend: Vercel

## ⚙️ Local Setup Instructions
